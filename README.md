# Pricodex

Fan-made character codex for *Princess Connect! Re:Dive* (Japanese server), as an installable web app:
https://mtk48.github.io/pricodex/

The files here are generated by `pipeline/pwa.py` in a private repo; do not edit them by hand, they are overwritten on every update.

Game data from the JP master database mirrored by [Expugn/priconne-database](https://github.com/Expugn/priconne-database). Character icons and background art © Cygames. Tiers and scores: GameWith. Not affiliated with Cygames.
